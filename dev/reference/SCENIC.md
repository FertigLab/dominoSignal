# SCENIC AUC subset

A subset of SCENIC AUCs as applied to PBMC data.

## Usage

``` r
data("SCENIC")
```

## Format

A list of:

- auc_tiny:

  A subset of SCENIC AUCs

- regulons_tiny:

  A subset of SCENIC regulons

- regulon_list_tiny:

  A subset of SCENIC regulons formatted as a regulon_list
