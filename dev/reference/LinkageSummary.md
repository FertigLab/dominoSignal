# Example linkage summary

A list containing a linkage summary object and a differential linkage
result from a mock dataset

- linkage_sum_tiny:

  A linkage summary object created with mock data.

- linkage_diff_tiny:

  Results from running
  [`test_differential_linkages()`](https://FertigLab.github.io/dominoSignal/dev/reference/test_differential_linkages.md)
  on the mock linkage summary object.

## Usage

``` r
data("LinkageSummary")
```

## Format

An object of class `list` of length 2.
