# Convert between ligand names and gene names

Convert between ligand names and gene names

## Usage

``` r
resolve_names(dom, genes)
```

## Arguments

- dom:

  A
  [`domino()`](https://FertigLab.github.io/dominoSignal/dev/reference/domino-class.md)
  object

- genes:

  A vector of genes on which to resolve ligand and gene names

## Value

A vector of names where ligand names have been replaced with gene names
if applicable
